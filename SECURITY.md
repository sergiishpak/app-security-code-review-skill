# Reporting a security problem

For a security problem in this skill, open the repository’s **Security and quality** tab and choose **Report a vulnerability**. Include the skill release or commit and a redacted description of the behavior. Keep private source code, credentials, and unresolved findings out of public issues.

For a vulnerability in an application reviewed with the skill, follow that application’s security policy and send the report to its maintainers through their private channel.

[GitHub private reporting instructions](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately)
